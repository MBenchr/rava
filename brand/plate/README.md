# La Marque d'origine - prototype protocol

Canonical dimensions: `42.07 x 26.00 x 1.20 mm`.

- Full horizontal rectangle.
- Four `0.8 mm` micro-radii.
- Dark silicon bronze.
- Fine horizontal brushing and matte patina.
- Flush installation with no visible screw.
- Inner right return of the lower horizontal opening.
- Front edge set back `28-32 mm`.
- Invisible in a strict frontal view.
- NFC behind the plate only after a ferrite and RF test.

## Print test

Open `isandre-origin-plate-1to1-a4.svg`, print at `100%`, disable all page
scaling and measure the `50.00 mm` control bar. Reject the proof if that bar is
not exact.

## Mandatory physical gates

1. ISANDRE is legible at 50 cm.
2. Test engraving depths `0.15 / 0.25 / 0.35 mm`.
3. Flush tolerance holds at `0 / +0.15 mm`.
4. NFC succeeds on at least 95% of trials across five phones.
5. Cleaning, humidity, abrasion and pull-out tests pass.
6. The production supplier outlines and validates all microtype.

The SVGs in this directory are prototypes, not production release files.
