# ISANDRE template kit

The templates apply one shared system to every channel:

- one dominant opening for approved imagery;
- wide limewash margins;
- ink typography;
- one restrained passage-cobalt rule;
- no repeated Entaille pattern;
- no fabricated workshop, provenance, owner or press proof.

Before release, replace every `APPROVED IMAGE` field with a rights-cleared
master and retain photographer, stylist, architecture and generative-image
credits in the asset record.
