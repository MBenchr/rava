# Protocole A5 — Matière, structure, sécurité et transport

Référence : `ISR-A5-TEST-001`  
Statut : protocole de consultation ; méthodes finales à valider par laboratoire

## 1. Règle de preuve

Les tests sont réalisés sur des échantillons identifiés par produit, finition,
lot matière, moule, cycle, date, opérateur et version de géométrie. Toute
modification de résine, pigment, moule, peau, insert, lest, finition ou
emballage déclenche une analyse de requalification.

Les seuils d’acceptation sont classés :

- `hard` : échec = rejet ou CAPA avant nouvelle présentation ;
- `target` : optimisation autorisée avant golden sample ;
- `laboratory-required` : méthode/seuil final déterminé par laboratoire.

## 2. Phase C0 — coupons

Pour chacune des quatre finitions :

- trois reliefs : `15–30`, `30–50`, `50–80 µm` ;
- trois brillances : `8`, `12`, `15 GU à 60°` ;
- un témoin `80–150 µm` destiné à confirmer le rejet ;
- un témoin GFRP de repli ;
- un rayon grandeur réelle ;
- une zone de joint/détourage ;
- un témoin d’insertion de plaque.

Dimensions minimales recommandées : `300 × 300 mm`, plus le tronçon moulé.

### Lecture sensorielle

| Contrôle | Méthode | Gate |
|---|---|---|
| couleur D65 | spectrophotomètre, trois zones | target, Delta E à fixer sur golden sample |
| lumière 2700 K | cabine + revue humaine | hard : aucune dérive sale ou grisâtre |
| brillance | glossmètre 60°, cinq points | target : 8–15 GU |
| relief | profilométrie ou méthode fournisseur corrélée | target : 30–50 µm |
| toucher | panel aveugle comparatif | target |
| porosité | loupe et essuyage coloré | hard : aucune porosité ouverte |
| rayure révélant autre couleur | rayure qualifiée | hard : refus |

### Taches et entretien

Tester à `1 h`, `24 h` et `7 jours` :

- café ;
- vin rouge ;
- huile ;
- sauce colorée ;
- crème solaire ;
- savon ;
- alcool ménager compatible ;
- eau calcaire ;
- encre soluble.

Documenter photo normalisée, Delta E, brillance avant/après et méthode de
nettoyage. Aucun produit agressif ne doit être ajouté au guide d’entretien
avant qualification.

### Résistance

- abrasion ;
- rayure ;
- impact bille ;
- chaleur sèche et humide ;
- cycles de nettoyage ;
- réparation contrôlée ;
- UV seulement pour préparer une future revendication extérieure.

## 3. Phase C1 — tronçon grandeur réelle

Le tronçon reproduit :

- rayon extérieur ;
- bord de niche ;
- section visuelle `80 mm` ;
- portée `640 mm` ;
- zone d’insert ;
- plan de joint, évent et détourage ;
- système de plaque ;
- finition avant, arrière et retour.

Mesures :

- épaisseur par cartographie ultrason ou coupe témoin ;
- masse ;
- flèche immédiate ;
- fluage sous charge pendant 30 jours minimum ;
- flèche résiduelle après décharge ;
- bruit au tapotement comparé aux coupons ;
- impact de chant ;
- arrachement insert ;
- nettoyage et réparation.

L’échantillon ne passe pas si le joint, l’évent, le détourage ou un sink mark
est visible depuis les angles usuels.

## 4. Phase P1 — prototype SEUIL

SEUIL est le premier article critique.

### Géométrie

- scan ou gabarit des dimensions externes ;
- contrôle des huit ouvertures et de leur ordre ;
- section visuelle ;
- rayons ;
- profondeur ;
- socle et retrait ;
- absence de fond ;
- planéité et torsion ;
- symétrie avant/arrière.

La géométrie canonique est un gate dur. Une bonne finition ne compense jamais
une forme incorrecte.

### Structure et sécurité

- charge par niche et surcharge définie avec le laboratoire ;
- charge excentrée au bord avant ;
- flèche et fluage ;
- poussée/traction dans les deux axes ;
- stabilité vide et chargé ;
- sol dur, tapis et sol irrégulier ;
- avec et sans lest ;
- avec et sans anti-basculement ;
- arrachement des points d’ancrage ;
- comportement sous usage prévisible d’un enfant ;
- absence de point coupant, pincement ou petite pièce accessible.

Les références à confirmer par le laboratoire sont `EN 14749:2016+A1:2022`,
`EN 16122` et le GPSR `(UE) 2023/988`. Le présent document ne constitue pas une
déclaration de conformité.

### Perception matérielle

- masse installée cible `80–88 kg` ;
- lest démontable cible `20–25 kg` ;
- aucun balancement ;
- aucune flexion locale sensible à la main ;
- aucun son creux dominant aux zones de contact ;
- patins invisibles et réglables ;
- aucune différence volontaire de traitement entre plans et rayons.

## 5. Phase P2 — prototype PORTÉE

Reprendre P1 avec priorité à :

- longues portées `580–640 mm` ;
- affaissement central ;
- charge asymétrique ;
- stabilité latérale ;
- répartition des patins ;
- nécessité réelle du lest `10–15 kg`.

La cible de poids installé `72–80 kg` reste une intention jusqu’à mesure.

## 6. Phase PK — système emballé

Le produit et l’emballage sont testés ensemble.

Séquence recommandée :

1. essai de développement ISTA 2C ;
2. corrections ;
3. qualification LTL selon ISTA 3B ou protocole laboratoire équivalent ;
4. route réelle de `1 000 km` ;
5. inspection produit, plaque, accessoires et emballage ;
6. répétition avec un nouvel ensemble pour la certification si nécessaire.

ISTA impose de choisir le protocole selon l’environnement de distribution. Le
laboratoire doit donc confirmer le mode réel : messagerie, LTL, palette,
livraison à deux personnes ou maritime.

Critères d’échec :

- fissure, déformation permanente ou ouverture modifiée ;
- abrasion ou transfert de mousse ;
- basculement dans l’emballage ;
- plaque ou finition marquée ;
- accessoire manquant ;
- humidité piégée ;
- emballage ne permettant plus une manutention sûre.

## 7. Phase GS — golden sample

Le golden sample est revu uniquement après clôture des tests critiques. Il est
signé, daté, scellé, photographié et stocké chez ISANDRE ; un jumeau contrôlé
reste chez le fabricant.

Il devient la référence pour couleur, brillance, toucher, son, géométrie,
assemblage, plaque, patins et emballage.

## 8. Rapports obligatoires

Chaque rapport contient :

- identifiant et version ;
- objectif ;
- laboratoire/fournisseur ;
- appareils et étalonnage ;
- méthode ;
- conditions ;
- échantillons ;
- données brutes ;
- photos avant/après ;
- écarts ;
- verdict ;
- NCR/CAPA ;
- approbations.

Une conclusion sans données brutes ni échantillon traçable n’est pas une preuve.
