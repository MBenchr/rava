# A8 — Glossaire public et interne

| Terme | Définition |
|---|---|
| Ouvert / open-backed | Fini et ouvert à l'arrière, sans panneau de fermeture |
| Fabriqué sur commande | La fabrication en Italie commence pour une commande confirmée ; aucune personnalisation implicite |
| Validé numériquement | Représentation approuvée, sans preuve physique de couleur ou matière |
| Concept bloqué | Direction visible mais non libérée comme preuve dimensionnelle ou industrielle |
| Golden sample | Référence physique signée pour matière, couleur et finition |
| Finition | Couleur et réponse de surface approuvées ensemble |
| Pièce | Un meuble de la collection ; éviter « sculpture » dans l'UI commerce |
| Collection ṬĀQA | Nom éditorial ; `TAQA` reste la forme technique ASCII |
| SEUIL 01 | Cabinet vertical ouvert |
| PORTÉE 02 | Cabinet horizontal ouvert |
| VEILLE 03 | Table de chevet ; dimensions encore bloquées |

## Interdits

- « béton » si le produit final n'est pas en béton ;
- « artisanal » sans processus réel documenté ;
- « fabriqué en France » avant H-004 ;
- « édition limitée » sans quantité, règles et preuve ;
- « best-seller », « viral », « sold out » ou presse inventée ;
- « sur mesure » pour une simple production sur commande.
