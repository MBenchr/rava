# Index de recherche — ISANDRE / ṬĀQA

Date de consolidation : 30 juillet 2026

Cet index définit l'ordre de lecture et évite que plusieurs cahiers deviennent des vérités concurrentes.

## Ordre d'autorité

1. Les données fabricant et dessins métriques validés sont la vérité produit.
2. Le catalogue applicatif est la vérité commerce.
3. Le plan maître organise l'exécution.
4. Les benchmarks expliquent les décisions, sans remplacer les données produit.
5. Les images générées sont des médias de contexte, jamais une preuve documentaire.

| Exigence | Preuve |

## Ordre d'exécution recommandé

1. Corriger les écarts P0 de l'audit.
2. Verrouiller vérité produit, origine, matière et dimensions.
3. Produire le système média canonique.
4. Réduire la home à quatre actes.
5. Aligner les trois PDP sur un buy panel partagé.
6. Stabiliser service, panier, checkout et projection.
7. Préparer trade, presse et contenu d'acquisition.
8. Mesurer, tester et lancer par marché.
