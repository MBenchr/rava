# Vague A6 — Production visuelle pilote

Date : 27 juillet 2026  
Statut : porte numérique passée ; libération physique ouverte

## Sélections

- SEUIL Craie : passage lumineux, direction A affinée.
- PORTÉE Sauge : séparation salon/salle à manger, direction C.
- VEILLE Argile rose : scène près du lit, direction C affinée, concept bloqué.

## Livrables

- trois directions par produit ;
- un rendu retenu par produit ;
- manifeste machine versionné ;
- recettes maîtres ;
- rapport QA géométrique et éditorial ;
- vérificateur automatisé ;
- archive lossless hors `public/`.

## Preuves numériques

- SEUIL et PORTÉE conservent huit ouvertures et des rapports de face dans la
  tolérance pilote de `±1,5 %` ;
- la matière paraît mate peau d’œuf, non plastique ;
- les focales et hauteurs de caméra restent dans les plages du plan maître ;
- aucun rendu n’est une fausse preuve de fabrication ou de client ;
- les assets pilotes ne sont pas servis par le storefront.

## Limites

- la fidélité colorimétrique attend les coupons et le golden sample ;
- VEILLE n’a pas de rapport métrique validé ;
- les pilotes ont une résolution de direction créative, pas encore les masters
  16 bits et ratios complets d’A7 ;
- l’approbation indépendante reste H-010.

## Porte A6

La porte numérique A6 est franchie pour SEUIL et PORTÉE. La production A7 peut
commencer avec les recettes figées. VEILLE reste sous statut
`concept-blocked` jusqu’à H-005.
